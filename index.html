Como funcionaDemoBaixar

Dois celulares. Uma TV. Zero fila.

DuoPlay Retro é um console pessoal para jogos clássicos na sua TV box. Use o celular como controle, escolha Jogador 1 ou 2 e jogue.

Versão 0.7.0 para TV box ARM32.

Arraste

Como funciona

Três passos, todos pelo mesmo Wi-Fi.

1

Abra os controles na TV

A TV mostra um QR code e um endereço local.

2

Escaneie com cada celular

Cada pessoa escolhe Jogador 1 ou 2 na página que abre no navegador.

3

Jogue

Os botões tocados chegam direto ao emulador, sem internet.

Teste os controles

Prévia interativa do que a TV vai exibir. Jogador 1: W e S. Jogador 2: setas. No celular, use os botões abaixo.

    Baixe o app

    Dois apps: um para a TV box e outro para o celular virar controle. Os downloads abrem no MediaFire. Para instalar, o Android pede para liberar a instalação de fontes desconhecidas.
